# MMM — гайд

**MMM** — панель для десятков аккаунтов Steam в одном окне.

## Старт

1. Бот **@mmmm_agent** → купи подписку → **⬇️ Скачать**
2. Запусти `MMM.exe` → окно с **Device ID** → **«Копировать»**
3. Бот → **🖥 Привязка HWID** → отправь Device ID
4. В MMM → **«Проверить активацию»**

{% hint style="info" %}
Всё хранится в папке с `MMM.exe`. Несколько копий в разных папках работают одновременно — только не держи один аккаунт в двух копиях
{% endhint %}
