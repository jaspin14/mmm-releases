# MMM — Guide

**MMM** is a panel for dozens of Steam accounts in one window.

## Start

1. Bot **@mmmm_agent** → buy a subscription → **⬇️ Download**
2. Run `MMM.exe` → window with **Device ID** → **Copy**
3. Bot → **🖥 HWID binding** → send the Device ID
4. In MMM → **Check activation**

{% hint style="info" %}
Everything is stored in the folder with `MMM.exe`. Several copies in different folders can run at once — just don't keep one account in two copies
{% endhint %}
